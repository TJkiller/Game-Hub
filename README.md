## 🎮 Game Hub - Ultimate Collection

## Welcome!

Welcome to Game Hub an exciting collection of interactive console games bundled into one project. Explore different worlds and test your skills and have loads of fun all from one place!

## 🧩 Games Included  

1. Quiz Game<br>  
Challenge yourself with general knowledge questions. Answer correctly earn points and get your final performance reviewed at the end!  
2. Number Guessing Game<br>  
Set your range and try to guess the secret number! Receive hints like "too high" or "too low" after each attempt.  
3. Rock, Paper, Scissors<br>  
Play the classic game against a computer opponent. Track your wins and see if you can beat the CPU in multiple rounds!  
4. Adventure Story Game<br>  
Choose your path in a mini text adventure. Make decisions wisely to reach your destination safely or face some hilarious (and dangerous) outcomes.  

## ✨ Key Features  

- 🎯 Intuitive menu navigation  
- 🏆 Progressive scoring system  
- 🤖 Smart computer opponents  
- 🎲 Randomized gameplay elements  
- 🔄 Seamless game restart functionality  
- ❌ Robust error handling  
- 😄 Humorous messages & responses  

## 🎮 Gameplay Tips  

- 💡 In Number Guesser: Type `QQ` for quick exit  
- 🏃 Adventure Game: Choices matter - think before deciding!  
- 📄 In Rock, Paper, Scissors: Use `Q` to quit gracefully  
- 🔄 Most games allow unlimited replays  
- 🆘 Invalid inputs will prompt you to try again  

## 📦 Installation Instructions  

### Step 1: Get the Code  
**Option 1: Clone Repository**  
```bash
git clone https://github.com/your-Tjkiller/game-hub.git
```  

**Option 2: Download ZIP**  
1. Click "Code" button on GitHub  
2. Select "Download ZIP"  
3. Extract files to your preferred location  

### Step 2: Verify Python Installation  
```bash
python --version  # Should show Python 3.x
```  

### Step 3: Launch the Game  
```bash
cd game-hub      # Navigate to project folder  
python game_hub.py
```  

## 🚀 How to Start Playing  

### Method 1: Using Visual Studio Code  
1. Clone/download the repository  
2. Open the project folder in VS Code  
3. Open the integrated terminal (Ctrl+`)  
4. Run:  
   ```bash 
   python game_hub.py
   ```  

### Method 2: Using Command Prompt/Terminal  
1. Open your terminal/command prompt  
2. Navigate to project directory:  
   ```bash
   cd path/to/game-hub
   ```  
3. Run:  
   ```bash
   python game_hub.py
   ```
